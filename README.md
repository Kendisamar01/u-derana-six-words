Entry for the [Six Words, One Story bounty on make.fun](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410).

The story: "Grandma winked, then forgot my name."

## Run

```sh
python3 main.py
```

`main.py` uses only the Python standard library. It checks that the story is
exactly six words (and within the gate's 60-character limit), then writes those
bytes as UTF-8 to `/output/entry.txt`. For local testing, set
`MAKEFUN_OUTPUT_DIR` to write into another directory instead.
